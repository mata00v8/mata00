Versión del manual: 1.0

1. Introducción

EL MATADOR - MATA00 es un dispositivo automotriz portátil diseñado para la lectura y eliminación de códigos de avería DTC y la monitorización en tiempo real de parámetros del motor mediante comunicación OBD2 sobre CAN BUS.

El equipo puede funcionar de dos maneras:

  • Como eliminador automático de fallos, sin necesidad de ordenador ni teléfono.
  • Como scanner automotriz, conectado a un ordenador Windows o a un teléfono Android.

2. Contenido del paquete

  • Unidad MATA00.
  • Cable USB.
  • Acceso mediante código QR a la página oficial de soporte.
  • Software para Windows.
  • Aplicación Android recomendada.
  • Manual de usuario online.

Para uso en Windows

  • Teléfono Android compatible con USB OTG.

4. Modo de uso

Existen dos modos de funcionamiento:

  • Modo Eliminador de Fallos
  • Modo Scanner Automotriz

Modo Eliminador de Fallos

Para este modo no es necesario utilizar ningún dispositivo externo, como ordenador o teléfono.

  1. Ponga el vehículo en contacto, con el motor apagado.
  2. Inserte EL MATADOR - MATA00 en la toma de diagnóstico OBD2 del vehículo.
  3. Espere aproximadamente 10 segundos.
  4. Retire el equipo de la toma OBD2.
  5. Ponga en marcha el motor.

Modo Scanner Automotriz

Este modo permite usar el equipo como scanner automotriz desde un ordenador o teléfono móvil.

  1. Conecte el cable USB al MATA00.
  2. Conecte el otro extremo del cable USB a la PC o al móvil.
  3. Espere aproximadamente 30 segundos.
  4. Localice el conector OBD2 del vehículo.
  5. Conecte el MATA00 al puerto OBD2.
  6. Coloque el contacto del vehículo en posición ON.
  7. Utilice el software de Windows o la aplicación Android para enviar comandos al equipo.

5. Uso en Windows

  1. Descargue el software MATA00 desde la página oficial.
  2. Descomprima el archivo ZIP.
  3. Ejecute el programa.
  4. Seleccione el puerto COM correspondiente al MATA00.
  5. Pulse conectar.
  6. Introduzca el comando deseado.

6. Uso en Android

  1. Instale la aplicación Serial USB Terminal.
  2. Conecte el teléfono al MATA00 mediante cable USB OTG.
  3. Abra la aplicación.
  4. Seleccione el dispositivo USB detectado.
  5. Configure la comunicación serie.

8. Lectura y borrado de averías

Leer averías confirmadas

Comando:

DTC

Leer averías pendientes

Comando:

PEND

Leer averías permanentes

Comando:

PERM

Borrar averías

Comando:

CLR
Importante: Algunos códigos permanentes no se eliminan inmediatamente con el borrado manual. En algunos vehículos pueden desaparecer luego de varios ciclos de conducción si la falla no vuelve a presentarse.

9. Indicaciones importantes

  • El borrado de averías puede apagar el testigo de motor si la falla ya no está presente.
  • No todos los vehículos soportan todos los parámetros OBD2.
  • El equipo está diseñado para vehículos con comunicación OBD2 CAN BUS.
  • Utilice el equipo de forma responsable y únicamente en vehículos compatibles.

10. Solución de problemas

No hay comunicación

  • Verifique que el vehículo esté en contacto.
  • Compruebe que el conector OBD2 esté bien insertado.
  • Revise el cable USB.
  • Confirme que el vehículo utilice OBD2 CAN BUS.

No aparecen algunos parámetros

El vehículo puede no soportar ese PID. Esto es normal en algunos modelos.

No se borran los fallos

Si la falla sigue presente, la ECU puede volver a registrar el código inmediatamente. También existen códigos permanentes que requieren ciclos de conducción para desaparecer.
